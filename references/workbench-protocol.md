# 可选工作台协议

网页工作台用于记录任务、状态和复盘；Skill 负责生成内容。二者可配套使用，但 Skill 不依赖工作台、站点登录或 API Key。

当前可选工作台地址：<https://mi-image-ai-toolkit.wyfdcjh.chatgpt.site/>

## 输入任务包

工作台任务应尽量使用以下格式复制给 Codex：

```markdown
【小米影像 AI 工作台任务】
任务 ID：IMG-2026-W31-001
模块：M1 内容策划
任务名称：秋季影像大赛征集
业务目标：提升有效投稿量
目标人群：手机摄影爱好者
平台：微博 / 小米社区 / 短视频
时间窗：2026-08-01 至 2026-08-14
输入材料：
- 已确认活动规则
- 历史内容与数据
约束：
- 不新增未经确认的奖项和产品能力
验收指标：
- 有效投稿量
- 投稿页访问到投稿的转化率
期望交付：选题矩阵、主方案、示例文案、指标设计
```

字段规则：

- `任务 ID`：原样保留；没有时写“未提供”，不得编造。
- `模块`：优先使用 M1–M10；模块名称与编号不一致时明确提示。
- `输入材料`：材料正文优先于仅提供链接；无法访问链接时请用户粘贴关键内容。
- `约束`：视为硬边界，除非用户明确修改。
- `验收指标`：没有基线时不承诺具体提升幅度。
- `期望交付`：决定输出重点，不强制展开全部默认章节。

## 缺失字段处理

1. 缺少目标、对象或核心事实，且会改变方向：先列最多 3 个关键问题。
2. 缺少次要信息但可以形成草案：明确假设并继续。
3. 缺少数据：输出数据模板和计算方法，不生成虚假趋势。
4. 含敏感数据：按 [governance.md](governance.md) 脱敏，不把原值写入回填块。

## 输出回填块

只有输入来自工作台，或用户明确要求“生成工作台回填内容”时，才在结果末尾附加：

```markdown
---
【工作台回填】
任务 ID：<原任务 ID 或未提供>
模块：<M1-M10 + 名称>
处理状态：待人工审核
一句话结论：<80 字以内>
核心产出：
- <可直接复制的要点 1>
- <可直接复制的要点 2>
待核验：
- <事实、数据、权限或品牌问题>
下一步：
- <负责人 / 截止时间 / 验收标准>
AI 使用记录：
- 协作环节：<策划 / 分析 / 改写 / 复盘等>
- 人工修改：<待填写>
- 实际采纳：<待填写>
- 节省时间：<待填写>
```

## 状态与权限

- Skill 只生成回填文本，不声称已写入网页、数据库或第三方系统。
- 用户完成事实、品牌和数据审核后，再在工作台中将状态改为“已审核”或“已完成”。
- 工作台不可访问时，直接在 Codex 中使用 Skill，不影响 M1–M10 能力。
- 工作台访问名单、账户激活和数据持久化由工作台管理员管理，与 Skill 安装权限分离。
