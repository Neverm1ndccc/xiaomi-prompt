# 质量、品牌与数据治理

任何涉及对外发布、产品事实、个人数据、竞品、版权或经营结论的任务，都必须执行本文件。

## 事实分层

- 已确认事实：用户材料直接支持，可正常表述。
- 合理推断：必须使用“可能、从当前样本看、建议验证”等限定语。
- 待核验信息：保留占位符，说明所需来源，不补写具体数字、链接或结论。
- 创作建议：明确是建议，不包装成已发生事实。

引用外部信息时回到原始、权威、可追溯来源。AI 输出本身不是来源。

## 发布红线

- 不虚构产品功能、参数、活动规则、奖项、合作关系、创作者经历和传播数据。
- 不生成绝对化效果承诺、无法证明的“第一”或贬损性竞品描述。
- 不把单一案例、短期相关性或小样本直接写成因果和长期趋势。
- 不公开个人隐私、内部账号、访问密钥、未发布业务信息或其他敏感数据。
- 不复制未经授权的摄影作品、长段文案、脚本或竞品创意表达。
- 不绕过品牌、法务、隐私、安全或发布审批。

## 品牌表达

- 专业、真诚、清晰、克制，避免夸张、油腻和机械客服感。
- 优先描述用户可感知、可实践的影像体验，技术名词服务于理解。
- 对摄影知识给出可操作步骤，并说明场景、设备和光线边界。
- 对投诉、安全和舆情先确认信息与情绪，再进入人工升级流程。

## 敏感数据处理

收到手机号、邮箱、身份证、账号密码、访问令牌、精确地址、未发布数据等信息时：

1. 不在输出中重复完整值。
2. 建议使用脱敏标识，例如 `创作者A`、`手机号尾号1234`。
3. 不将敏感内容写入示例、知识库、日志、README 或 Git 仓库。
4. 如果完成任务并不需要这些数据，提醒用户删除或改用安全渠道。

## 数据结论检查

发布数据结论前逐项确认：

- 指标定义、单位、去重方式、时间窗和归因窗口一致。
- 对比基线明确，没有把累计值与单周值直接比较。
- 0 值、空值、异常值和口径变化已经单独处理。
- 推断附带证据、反证和置信度，没有把相关性写成因果。
- 行动项能够在明确日期用明确指标复核。

## AI 效果举证

建议每周保留：

- AI 任务量与覆盖模块。
- 结果采纳率：实际采用的 AI 产出 / 已完成 AI 任务。
- 平均节省时间：同类任务人工基线耗时减去 AI 协作耗时。
- 一次通过率：无需重大修改即可通过审核的任务 / 已审核任务。
- 重大错误数：事实、版权、品牌、隐私或安全类严重问题。
- 方法沉淀：新增 Prompt、模板、规则、工具或流程。
- 推广记录：分享/培训次数、参与人数、采纳人数和复用次数。

只有基线、样本量、统计周期和任务复杂度可比时，才把效率或质量变化描述为 AI 带来的增量。否则写为“观察到的协同变化，待对照验证”。

## 人工审核清单

- [ ] 事实和产品能力有可追溯依据。
- [ ] 数据口径、公式和时间窗一致。
- [ ] 无隐私、密钥、内部敏感或未授权版权内容。
- [ ] 品牌表述不过度承诺、不攻击竞品。
- [ ] 推断、建议和事实已清楚区分。
- [ ] 负责人确认发布、合作或数据决策。
