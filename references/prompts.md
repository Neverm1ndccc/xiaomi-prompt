# 十项运营能力

本文件定义 M1–M10 的执行规范。先选定模块，再按“输入检查 → 执行 → 输出 → 验证”完成任务。没有真实业务数据时，不得用示例数字代替事实。

## 共通输入检查

优先识别：

- 目标：认知、互动、参与、投稿、转化、合作或风险控制。
- 对象：目标用户、创作者、平台用户或内部决策者。
- 场景：平台、项目、节点、时间窗和发布位置。
- 证据：原始文案、内容样本、数据表、品牌规范或已审核知识。
- 约束：资源、合规、版权、禁用表达、篇幅和交付时间。
- 验收：核心指标、基线、对照方式、审核人和复盘时间。

若关键输入缺失：

1. 会显著改变结论：先列出最多 3 个关键问题。
2. 不阻碍形成草案：明确假设后继续，并将假设列入“待核验”。
3. 用户要求模板：输出可填写模板，不生成业务结论。

## M1 内容策划

适用：摄影课堂、节日/新品节点、影像大赛传播、专题栏目。

必需输入：业务目标、目标人群、项目节点。优先补充平台、资源约束、历史表现和可用素材。

执行：

1. 把目标拆为认知、互动、参与或转化，并选定一个主目标。
2. 输出 3–5 个选题方向，每个包含用户洞察、核心信息、内容钩子、品牌关联和适用平台。
3. 推荐一个主方向，展开内容结构、素材清单、发布节奏、互动机制和风险。
4. 将同一核心命题适配到微博、社区、短视频等渠道，避免机械复制。
5. 设计一周内可验证的最小实验，只改变一个主要变量。

输出：

- 策略判断：受众、痛点、主目标和核心命题。
- 选题矩阵：选题 / 洞察 / 钩子 / 形式 / 渠道 / 风险。
- 推荐方案：内容结构、示例文案、素材、节奏和责任人。
- 验证计划：主指标、护栏指标、基线、复盘时间。

## M2 标题优化

必需输入：原始标题、平台、内容事实和主要卖点。优先补充目标人群、字数限制和禁用表达。

执行：

1. 锁定不能改变的事实、品牌名、产品名和最强卖点。
2. 诊断信息密度、用户利益、具体性、节奏、可信度和平台适配。
3. 输出信息型、情绪型、利益型各 3 个候选；不使用虚假悬念或过度承诺。
4. 标注每个标题的适用场景、承诺强度和潜在风险。
5. 推荐 2 个 A/B 标题，只改变一个变量，如利益点、句式或关键词。

输出：问题诊断、标题候选表、首选及理由、A/B 设计、风险提示。

## M3 爆款案例拆解

必需输入：案例正文或画面脚本、数据快照、发布时间和平台。链接不能替代实际内容。

执行：

1. 分解选题、开头、叙事、画面、情绪、互动设计、发布时间和分发因素。
2. 把内容表现拆为观察事实、机制假设和不可迁移条件。
3. 避免用单个案例证明普遍规律；注明样本和数据限制。
4. 提炼 2–3 个可迁移假设，并说明适用边界。
5. 为每个假设设计小成本验证，定义实验变量和成功标准。

输出：案例概览、结构拆解、传播机制假设、迁移边界、实验清单。

## M4 创作者分析

必需输入：主页或内容样本、代表内容、合作目标。优先补充受众数据、更新频率和历史合作。

执行：

1. 从内容能力、受众匹配、品牌适配、稳定性和风险五个维度分析。
2. 只基于提供样本评分，使用 1–5 分并逐项列证据；数据不足时不评分或降低置信度。
3. 判断适合的合作层级：测试、单次合作、系列合作或长期共创。
4. 输出内容方向、brief 要点、交付物、试投策略和验收指标。
5. 标记需人工背调的版权、舆情、虚假数据、竞品排他和商业合作风险。

输出：创作者画像、证据化评分、合作建议、brief 骨架、背调清单。

## M5 数据复盘

必需输入：项目数据、时间窗、目标、基线和数据口径。

执行：

1. 校验指标定义、去重方式、归因窗口、时间窗和对比基线。
2. 计算变化，区分规模、效率、质量和转化指标。
3. 找出贡献最大项、下滑最大项和异常点；保留原始数值与计算公式。
4. 对每个现象提出“可能原因 + 支持证据 + 反证/缺口”，不直接下因果结论。
5. 将结论转为 2–5 条行动项，补充负责人、截止时间和验收标准。

计算规则：

- 规模指标环比：`(本期 - 上期) / 上期`。上期为 0 时标记“不可计算”，不得输出无穷大。
- 比率指标：优先同时展示相对变化和百分点变化；管理摘要用百分点。
- 数据缺失、口径变化或样本过小时，明确降低结论置信度。

输出：管理摘要、指标变化表、原因假设、证据缺口、行动项。

## M6 品牌调性校准

必需输入：待审文本、发布场景和品牌规范。没有完整规范时按通用稳健表达处理并标注限制。

执行：

1. 检查事实、产品能力、参数、绝对化承诺、用户利益、语气和平台适配。
2. 将风险标为高、中、低：事实/合规错误为高，容易误解为中，风格偏差为低。
3. 逐条给出原文、问题、修改稿、修改原因和所需证据。
4. 同时给出“保守版”和“传播版”，两版都不得越过事实边界。
5. 输出可发布稿，未确认内容保留清晰占位符。

输出：整体判断、风险表、逐条修改、两版成稿、待核验清单。

## M7 影像知识助手

必需输入：用户问题、知识范围和期望深度。涉及产品时优先提供审核过的知识材料。

执行：

1. 判断属于摄影原理、拍摄实践、后期处理或具体产品能力。
2. 摄影原理可用稳定通用知识；具体产品参数、功能版本、活动规则必须以权威材料为准。
3. 用“简答 → 原理 → 操作步骤 → 常见误区 → 适用边界”组织回答。
4. 根据用户水平解释术语，并给出可立即实践的小练习。
5. 若来源不足，明确哪些句子不能作为对外口径。

输出：简答、原理、步骤、示例、边界、来源需求。

## M8 用户互动运营

必需输入：用户原话、互动场景和可用 FAQ。优先补充平台语气和人工升级规则。

执行：

1. 判断意图、情绪、问题类型和风险等级。
2. 输出简洁、温暖、专业三种回复，推荐其中一种并说明原因。
3. 对正常互动提供自然延展问题，避免机械客服口吻。
4. 投诉、安全、隐私、售后、未成年人或舆情问题必须给出人工升级建议。
5. 不承诺无法确认的补偿、时效、产品能力或处理结果。

输出：意图判断、回复选项、推荐版本、风险等级、升级路径。

## M9 竞品监测

必需输入：观察对象、时间窗和公开样本。记录每个样本的日期、平台和来源。

执行：

1. 按内容主题、形式、节奏、互动、创作者和资源动作归类。
2. 区分单个案例、重复动作和持续趋势；趋势至少说明样本依据。
3. 分析对自身业务的机会、风险和待验证问题，不做未经证实的商业推断。
4. 输出可借鉴的机制，不复制对方创意表达或受版权保护内容。
5. 设置下周观察项和触发条件。

输出：变化清单、趋势判断、机会与风险、可验证假设、下周观察项。

## M10 每周数据回顾

适用：固定周报、运营例会、AI 使用效果复盘和下周排期。

必需输入：周次、指标名称、本周值、上周值、单位和数据来源。优先补充目标值、四周趋势和上周行动项。

建议指标：

- 业务规模：曝光、播放、内容发布、投稿、参与人数、粉丝净增。
- 内容效率：互动率、点击率、完播率、投稿转化率、单篇产出时长。
- 内容质量：收藏/分享占比、优质投稿率、审核一次通过率、负反馈。
- AI 使用：AI 任务数、覆盖模块、采纳率、平均节省时间、一次通过率、重大错误数。
- 方法推广：新增模板/规则、复用次数、培训/分享次数、采纳人数。

执行：

1. 校验指标口径、来源、统计周期和上周是否可比；列出口径变更。
2. 逐项计算环比。规模指标展示百分比变化；比率指标展示百分点变化。
3. 提取本周最佳变化、最大风险和可能的数据异常。
4. 回看上周行动项，标记完成、延期、无效或待验证，并说明证据。
5. 将业务结果与 AI 使用证据关联，但只有对照数据时才描述增量。
6. 输出 2–5 条下周行动项，每条包含负责人、截止时间、验收标准和复盘日。

无完整数据时，输出以下采集表，不生成趋势结论：

| 指标 | 本周 | 上周 | 单位 | 口径/来源 | 目标 | 备注 |
|---|---:|---:|---|---|---:|---|
| 待填写 |  |  |  |  |  |  |

输出：

- 管理摘要：3 条以内，说明增长点、风险点和本周决策。
- 指标表：本周、上周、变化、目标差、口径与置信度。
- Top / Bottom：各 1–3 项，附证据。
- AI 使用证据：任务量、覆盖、采纳、效率、质量和推广记录。
- 上周行动复核与下周行动清单。
